## 3. الحالة

| البند | الحالة |
| --- | --- |
| الوثائق الأربع | مكتوبة، بانتظار قراءتك |
| القرارات | **3 محسومة · 2 مفتوحان** |
| الأنظمة المدروسة | ثلاثة: `vectorbt` · `WyckoffTradingAgent` · `myra` — الخلاصة في §15 من `03` |
| أرشيف EGX الخارجي | فُحص ورُفض: 32% شموع غير متماسكة وتواريخ مزاحة — §5.2 من `02` |
| إطار الدورات | **مركزي أرضي** صريحًا؛ والفارق عن الشمسي يصل شهرين — §10.5 |
| **وحدة القياس** | جان: السعر والزمن رقم واحد بكلمتين — `tools/gann_number.py` §17 |
| **الأرشيف الكامل** | 8 ملفات MetaStock · **960,600 صفًا · 286 سهمًا · إلى 2025-10-27** · وثلاث نسخ مدموجة — §5.4 |
| **قاعدة EGX** | `M-Abdelmegeed/Project-EGX` — 262 سهمًا، 622,793 صفًا؛ الفورك محجوب بالتوكن — §5.3 |
| **السلاسل** | 1357 · 2468 · 1234 — الخطوة 2 = دورة كاملة؛ الأركان 315°/135° — §24 |
| **الصورة** | فردية/زوجية = تكافؤ الأس؛ ×10 = نصف دورة؛ والجذر يحتاج دائرتين — §23 |
| **الدائرة المضاعفة** | الرقم لا يتغير بنقل العلامة: `--mul درجة` · `--near درجة --log --prices ملف` — §22 |
| **البحث عن سعر** | `--near درجة --prices ملف` — والمطابقة وحدها ليست اكتشافًا: معها ضابط الـ360° — §21 |
| **الخريطة الدائرية** | 24 خلية × 15°، 0° عند 290، والطول الفلكى = الموضع + 240° — §20 |
| **الكسور** | المربع شبكة لا خط: الكسر بين 144 و145 لا داخلهما — §19 |
| ميكولا | الكتابان: تحويل السعر إلى طول، ومربع التسعة، ودورة المكعب — ورصد تعارض الخريطتين §18 |
| آلات تطوير الأفكار | ست أدوات مقيَّمة في §16 من `03`: `stumpy` · `ruptures` · `alphalens` · `skill-backtest-overfit` · `purged-CV` · مرجع الكواكب |
| الكود | عشرة ملفات في `tools/`: ثلاثة للتحقق الفلكى (`astro_conjunctions` · `gann_number` · `mikula_price_longitude`)، وسبعة للأرشيف (`egx_load` · `egx_calendar` · `egx_pair_control` · `egx_astro_test` · `egx_activity_rotation` · `egx_selection_rule` · `egx_pulse`) |

## 4. الأدوات

| الملف | ما يفعله |
| --- | --- |
| [`tools/astro_conjunctions.py`](tools/astro_conjunctions.py) | يحسب تواريخ اقتران المشتري بزحل 1900–2050 من عناصر كبلرية منشورة، بلا مكتبة خارجية. غرضه **التحقق**: أن دورة العشرين سنة تقويمُ أحداث لا رقم ثابت |
| [`tools/egx_load.py`](tools/egx_load.py) | يكتشف نسخ الأرشيف الثلاث، ويختار الأحدث لكل سهم، ويُخرج السلسلة النظيفة، ويطبع فحص الشمعة والتقويم — §5.4 من `02` |
| [`tools/egx_calendar.py`](tools/egx_calendar.py) | كشف الانعطافات بارتداد نسبى، واختبار التزامن بإزاحة دورية، واختبار الدورية بضجيج أحمر AR(1) — §14 من `03` |
| [`tools/egx_pair_control.py`](tools/egx_pair_control.py) | الضبط على «زمرة التقويم»: هل يبقى تزامن الزوج بعد نزع كثافة السهم وتشابه عوائده؟ الجواب: لا — §14.3.2 |
| [`tools/egx_astro_test.py`](tools/egx_astro_test.py) | الاختبار الفلكى: هل تقع الانعطافات عند زوايا الكواكب (15 زوجًا · 9 زوايا)؟ الجواب: 0.6% فرقًا عن الضابط — §14.8 |
| [`tools/egx_activity_rotation.py`](tools/egx_activity_rotation.py) | هل يدور النشاط بين الأسهم؟ ارتباط الرتب +0.888 سنة/سنة — أى ثبات لا دوران — §17.3 من `04` |
| [`tools/egx_selection_rule.py`](tools/egx_selection_rule.py) | قاعدة جان «قمم أعلى وقيعان أعلى»: +1.80 نقطة لكل 6 أشهر، وt=+0.72 — اتجاه لا دليل — §17.9 |
| [`tools/egx_pulse.py`](tools/egx_pulse.py) | نبض السهم: φ=360·log₁₀ P، وω هو الثابت الوحيد تحت المضاعفة؛ والدورة 310 أيام وسيطًا — والتكدّس عند 45° أثر عتبة الكشف — §14.9 |
